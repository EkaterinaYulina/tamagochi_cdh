# Тамагочи для Яндекс Игр

HTML5-игра про питомца (кот, пёс, хомяк) в стиле мягкой 3D-анимации.

## Структура
- `index.html` — вся игра в одном файле (логика, стили, Яндекс SDK)
- `assets/` — спрайты `<вид>_<окрас>_<стадия>_<состояние>.webp`, фоны `bg_room.webp` и `bg_room_night.webp`, шрифты Nunito
- `PROMPTS_GEMINI.md` — готовые промпты для генерации спрайтов в Gemini
- `prepare_assets.py` — обработка картинок: удаление фона, обрезка, WebP до 512 px

## Запуск локально
```
python3 -m http.server 8000
```
Открыть http://localhost:8000. Через двойной клик по файлу картинки могут не загрузиться.

## Что готово
Белый кот: 3 стадии × 4 состояния (happy, sad, sleep, eat). Пёс и хомяк пока рисуются кодом (SVG).

## Публикация в Яндекс Играх
Загрузить архив с `index.html` и папкой `assets`. Таблицу лидеров `catch` создать в консоли разработчика.
