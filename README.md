# Тамагочи для Яндекс Игр

HTML5-игра про питомца (кот, пёс, хомяк) в стиле мягкой 3D-анимации.

## Структура
- `index.html` — вся игра в одном файле (логика, стили, Яндекс SDK)
- `assets/` — спрайты `<вид>_<окрас>_<стадия>_<состояние>.webp`, фоны `bg_room.webp` и `bg_room_night.webp`, шрифты Nunito
  - предметы комнаты `decor_<id>.webp` (id: bowl, bed, picture, clock, shelf, starlamp, rugpink, rugblue, house, post, aqua)
  - темы `bg_<winter|spring|space>.webp` и `bg_<тема>_night.webp`
  - образы `<вид>_<окрас>_<стадия>_<состояние>_<hat|glasses|bow>.webp`
  - платные окрасы: те же спрайты с окрасом 1 или 2
- `PROMPTS_GEMINI.md` — готовые промпты для генерации спрайтов в Gemini
- `prepare_assets.py` — обработка картинок: удаление фона, обрезка, WebP до 512 px

## Магазин
Четыре вкладки: еда (расходники), комната (декор по слотам, темы), витрина дня (3 предмета, скидка −30%, награды за видео), питомцы (до 3 питомцев, окрас, образ).
Всё, для чего ещё нет картинки, работает с запасным вариантом: декор рисуется SVG, темы дают цветокор и частицы. Образы и платные окрасы появляются в магазине сами, как только в `assets/` лежат нужные файлы.

## Запуск локально
```
python3 -m http.server 8000
```
Открыть http://localhost:8000. Через двойной клик по файлу картинки могут не загрузиться.

## Что готово
Белый кот: 3 стадии × 4 состояния (happy, sad, sleep, eat), тёплый свет после P-RELIGHT. Пёс и хомяк пока рисуются кодом (SVG). Магазин и декор работают на запасных картинках.

## Публикация в Яндекс Играх
Загрузить архив с `index.html` и папкой `assets`. Таблицу лидеров `catch` создать в консоли разработчика.
